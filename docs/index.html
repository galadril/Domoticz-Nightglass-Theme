Nightglass Premium Dark Theme for Domoticz

A sophisticated dark/light theme that transforms your Domoticz home automation dashboard into a focused, control-room experience — deep navy surfaces, smart device icons, sparkline charts, and a command palette that puts every device at your fingertips.

View on GitHub Install

What is Nightglass?

Nightglass is a drop-in theme for Domoticz. Clone the repository into Domoticz's www/styles/ directory — custom.css and custom.js are thin loaders that pull in the full theme from the src/css/ and src/js/ modules — and your dashboard is transformed.

The CSS layer handles all visual styling: color tokens, card layout, glassmorphism login, responsive navbar, and full dark/light mode support via a single body.dz-light class toggle. The JS layer adds intelligence: automatic Font Awesome icon replacement for every device type, live sparkline micro-charts, a command palette, keyboard shortcuts, cloud-synced settings, and more.

Command Palette
Ctrl+K — global fuzzy search and device control from any page, like Spotlight for your home.
Sparkline Charts
Inline SVG micro-charts on every sensor card showing the last 24h trend — temperature, humidity, rain, wind, and more.
Smart Icon System
90+ device types automatically mapped to Font Awesome icons with correct on/off colors, glow effects, and wind rotation.
Dark / Light Mode
Full peer dark and light color systems. One-click toggle, OS auto-detection, and per-mode color customization.
Server-Side Sync
Settings live on the Domoticz server, per user — your theme follows you across every browser and device automatically.
Live Toasts
Device changes surface as toasts straight off the WebSocket feed, backed by a navbar bell and a history panel on the N key.

Installation

Nightglass is a drop-in theme. No build step, no Node, no dependencies — clone it once and activate in Domoticz settings.

1

Navigate to your Domoticz styles directory

Domoticz loads custom themes from www/styles/ inside its install directory.

bash 
cd /home/pi/domoticz/www/styles/
2

Clone the repository into a theme folder

The folder name determines the theme name shown in Domoticz. You can call it anything — nightglass is the conventional name.

bash 
git clone https://github.com/galadril/Domoticz-Nightglass-Theme.git nightglass

Or update an existing installation:

bash 
cd nightglass && git pull

Copy the whole repository, not just the two root files. custom.css and custom.js are thin loaders: the CSS lives in src/css/, the JS modules in src/js/, the 16 built-in palettes in themes/ (fetched at runtime, one JSON per preset), and the logo in images/. A partial copy fails quietly — missing preset files are skipped without an error, so the presets grid simply comes up empty.

3

Restart Domoticz (first-time install only)

Domoticz needs a restart to detect the new theme directory. Not required for updates.

bash 
sudo systemctl restart domoticz
4

Activate in Domoticz

Go to Setup → Settings → Interface and set the theme to Nightglass. Save and reload.

Note: Nightglass overrides the Default theme CSS. The folder name you choose is what appears in the Domoticz theme dropdown — it does not have to be nightglass.

Visual Design

Nightglass uses a deep navy color palette with a single cool-blue accent that carries all interactive meaning — links, focus rings, active borders, and on-state icon color. Surface depth is created by stepping through surface-container levels, not by varying hue.

Elevation System
Four elevation levels using surface-container tokens. Glassmorphism reserved for modals & login — never on live device cards.
Smooth Animations
State-change flash, 3D card tilt, ambient device glow, and staggered navbar entrance. All respect prefers-reduced-motion.
Sensor Value Accents
Cards pick up a colour-coded top border from the reading itself — temperature, humidity, CO₂, UV, rain, wind and visibility.
Fully Responsive
Navbar collapses to a hamburger, cards reflow to single column, filter drawer becomes mobile-optimized. Works on tablets and phones.
Staleness Indicator
Devices with no update for a configurable time period get a visual stale marker — instantly spot offline or stuck sensors.
System Font Stack
Zero web fonts. Text renders in the OS typeface — zero latency, zero layout shift, beautifully anti-aliased on every platform.

Smart Features

The JS layer adds a layer of intelligence on top of the Domoticz AngularJS application without modifying any Domoticz files.

Live WebSocket Updates

Real-time card updates via Angular's device_update events — device values, icons, and timestamps update without any page refresh. State changes trigger a brief flash animation to draw your eye to what just changed.

Sparkline Micro-Charts

Every sensor card that supports history (temperature, humidity, rain, wind speed, counters, UV index) gets an inline SVG area chart injected beneath the value. Data is fetched from the Domoticz JSON API and rendered as a 24-hour trend.

Timestamp Formatting

Raw Domoticz timestamps are reformatted to human-readable relative labels: today 3:42 pm, yesterday 10:15 am, Apr 3, 2:00 pm. Each card gets a pinned footer bar with the formatted timestamp.

Live Toasts

Device changes arriving on the WebSocket feed surface as toasts in the corner of the screen. The Event Filter defaults to meaningful — switches and event-style sensors only, so a temperature probe reporting every minute does not toast — and can be widened to every device change. Duration (2–10s), corner, and a per-device suppression list are all configurable under Live Notifications in the settings panel.

Notification History

Toasts are ephemeral; the history panel is the record. A bell in the navbar accumulates the last 50 device updates with an unread badge, and clicking an entry jumps to that device's card and highlights it. Open it from the bell or with N; Esc closes it. On desktop it slides in from the right, on mobile up from the bottom. The list is scoped to the devices your Domoticz account can see.

Animated Device Icons

Icons can carry a per-device animation chosen in the Icon Studio — spin, glow, flicker and six more. The whole layer is gated on Animate Device Icons, so a dashboard on a wall panel can keep the icons still.

Dashboard 2.0 Enhancements

Domoticz's Dashboard 2.0 (dd- widgets) gets the same treatment as the classic pages: glass card surfaces, entrance animations, a right-click context menu on widgets, and a fullscreen mode for wall-mounted displays.

Ace Editor & Highcharts Theming

The Events page Ace editor automatically applies and persists your chosen theme (in localStorage, under dz-ace-theme — it follows whatever you pick in Domoticz's own theme dropdown). Highcharts panels (device history, reports) get a full dark or light palette applied globally — no chart looks out of place.

Icon System

Every Domoticz PNG device image is automatically replaced with a Font Awesome 7 icon using a two-pass replacement strategy: initial scan on load, then delta updates via MutationObserver watching image src attribute changes.

Device Map

90+ device types are mapped in DEVICE_MAP inside src/js/icons.js. Each entry specifies an icon class, an on-state color, and an off-state color:

javascript 
// Add a new device type to DEVICE_MAP:
"ChargingStation48": {
    icon:     "fa-solid fa-charging-station",
    colorOn:  "#4e9af1",
    colorOff: "#6c757d"
}

Per-Device Overrides

Individual devices can override their icon and color from the Nightglass Settings panel in Domoticz — no code changes needed. See Per-Device Overrides.

Light & Colour Control

Every place Domoticz asks for a colour is rebuilt: the device popup, and the in-page control on the device, scene, group and timer edit pages. Both drive Domoticz's own colour pipeline, so protected devices still prompt for a passcode and staged values (timers) still stage rather than send.

The Device Popup

  • Colour wheel — canvas hue/saturation wheel with a live preview swatch
  • Warmth bar — cool-to-warm gradient for white and tunable-white lights
  • Brightness — slider plus a typed percentage, whichever is quicker
  • Presets — On and Off as one-press buttons, plus Full and Night on colour lights
  • Instant apply — every control acts as you use it; there is no "Set Colour" step, and switching tabs deliberately does not send, so browsing the White tab can't turn an off light on

The popup adapts to the light: an RGB device gets the wheel only, RGBW/RGBWW gain a White tab, and WW/CW devices open straight onto the warmth bar.

Typing an Exact Colour or White

The preview field is editable. On the colour side it takes a hex value — type or paste #ff8800 instead of hunting for it on the wheel. On the warmth side it takes kelvin (2700–6500 K), which is the unit lamps are actually sold in; Domoticz's underlying warmth axis is a unitless 0–255, so an exact white was previously something you could drag to but never reproduce.

Recently Used Colours & Whites

Every picker in the theme feeds one shared strip of the last five colours you committed to — the popup, the in-page picker, the settings panel, per-device icon colours, and Domoticz's own colour fields (bar and gauge ranges, Dashboard 2.0 widget settings). Match two devices without copying a hex code around.

Colour temperatures keep a second, separate strip, shown beside the warmth bar and labelled in kelvin on hover. A white is not a hue: it drives a different control and can't stand in for a colour, so the two lists never crowd each other out. Setting the same 3200 K across a row of WW lamps is one click each.

Command Palette Features

  • Fuzzy search — type lvng lght to find "Living Room Light"
  • Favorites first — shows starred devices by default
  • Live state — current on/off/level/temp with color coding
  • Dimmer slider — inline 0–100% brightness control
  • Smart routing — auto-navigates to the correct page for each device type

Notification History — N

Toggles the notification panel — the last 50 device updates, so a change you missed is still there to read. Esc closes it. Like the number keys and /, it is ignored while an input is focused.

Filter Bar

A multi-dimensional filter panel that replaces Domoticz's native room selector on every device page — pure client-side, zero page reloads.

The filter bar appears below the top bar on all category pages (Dashboard, Switches, Temperature, etc.). It offers five filter dimensions that can be combined:

DimensionOptionsBehavior
RoomsAll plans from DomoticzPersists across page navigation
TypeSwitch types & sensor types on current pagePruned when navigating to a new page
HardwareHardware names on current pagePruned when navigating to a new page
StatusDevice state on the current page (on / off / open / closed …)Pruned when navigating to a new page
FavouritesOn / Off togglePruned when not relevant on new page

All filtering is AND-ed across dimensions and OR-ed within each dimension. The filter bar patches Angular's dashboardService.loadFavorites and livesocket.getJson to always fetch all devices (not just the current room's subset), so every device is in the DOM for instant client-side show/hide.

Open or close the filter panel with the Filters button in the search bar. On mobile it slides in as a full-height drawer with a backdrop.

Saving Your Own

Once you have the colours where you want them, Save current colors as preset adds them to the same grid alongside the sixteen built-ins, so you can jump back after experimenting — or keep one palette for the wall tablet and another for the desktop. Your presets are stored server-side with the rest of your settings and travel with them through export and import.

The built-in palettes ship as one JSON file each in the theme's themes/ directory and are fetched when the presets grid opens — which is why that directory has to come along with the rest of the repository.

Per-Device Icon Overrides

Assign a custom Font Awesome icon, on-color, and off-color to any individual device — no code changes required.

Open the Nightglass settings panel, go to Device Icons → Per-Device Icons, search for your device by name or idx, then pick any Font Awesome 7 icon from the Icon Studio and choose its colours and animation. Overrides are stored with the rest of your settings, server-side, so they follow you between browsers.

  • Visual icon picker with live search across all Font Awesome icons, plus any extra libraries installed in Domoticz
  • Separate on-state and off-state colours with live preview
  • A per-device animation — spin, glow, flicker and six more
  • Overrides take effect immediately without a page reload
  • Remove any override to revert to the automatic icon from DEVICE_MAP

On Domoticz builds that own the icon themselves, the shape is saved in Domoticz's own Icon column and Nightglass stores only the colours and animation — the same dialog, one less thing duplicated.

Extra Icon Libraries

Extra icon fonts are installed in Domoticz itself, under Setup → Custom Icons: give it a source URL and a class prefix and Domoticz downloads, stores and serves the library for every browser on the server.

  • Nothing to configure in Nightglass — installed libraries appear in the Icon Studio on their own
  • Each one gets its own group in the picker, searchable alongside Font Awesome
  • Adding, refreshing and removing a library all happen on Domoticz's own page

Sync & Export

Nightglass settings live on the Domoticz server rather than in the browser, so your theme automatically follows you to any browser or device signed in to the same server.

Where Settings Are Stored

On current Domoticz builds the theme uses Domoticz's own per-user theme settings API — settings are attached to your Domoticz account, so two people sharing a server can each have their own palette. On older builds without that API, the theme falls back to user variables (ngTheme_settings, plus ngTheme_presets for saved palettes, which are kept separate to stay under the user-variable size cap). If the server cannot be reached at all, changes are held in localStorage for the session so the interface still behaves — they just don't sync anywhere.

StorageWhatWhen
Domoticz theme settings (per user)All settings — primary storeOn every change, debounced
User variables ngTheme_*All settings — legacy fallbackOnly on builds without the theme settings API
localStorageDark/light preference (dz-theme-style), Ace theme, recent colours & whites; whole-settings cache when the server is unreachableInstantly — these are per browser by design
JSON export fileFull settings snapshotManual export

Import / Export

The settings panel footer has one-click Export and Import buttons. Export saves your full colour theme, feature flags, saved presets and per-device icon overrides as a single JSON file to share or back up.

Settings are read and written through window.dzNightglassSettings.get(key) and .set(key, value), whichever store is in use. Every feature flag is gated on these, which is what makes adding a new settings-controlled behaviour cheap.

Dark / Light Mode

Nightglass ships with a full peer dark and light color system — light mode is not an afterthought, every color token has a light-mode counterpart.

The sun/moon button injected into the navbar cycles between dark → light → auto. In auto mode the OS prefers-color-scheme is respected and live OS theme changes are applied without a reload. The preference is stored in localStorage under the key dz-theme-style.

Light mode is implemented as a single body.dz-light class override — all dark-mode tokens in :root are re-declared in body.dz-light with light-palette values. This means any third-party CSS targeting Domoticz elements will also respond correctly if it uses the --dz-* variables.

The color editor lets you set separate accent, surface, and text colors for dark and light modes independently.

Troubleshooting

Theme not showing after installation

Make sure the theme folder is directly inside www/styles/ and contains both custom.css and custom.js plus the src/ directory. Restart Domoticz once after cloning, then select the theme by folder name in Setup → Settings → Interface → Theme.

Icons not replacing / showing broken images

The icon replacement patches into Angular's rendering cycle. If icons appear as broken PNGs, check the browser console for JS errors. Make sure Font Awesome is loading — it ships with Domoticz but can be blocked by ad-blockers. Try disabling extensions.

Sparklines not appearing

Sparklines require a successful call to json.htm?type=graph. If the Domoticz API is unreachable from the client, they silently skip. Enable Debug Logging in the Nightglass settings panel and check the browser console for [Spark] log lines.

No theme presets in the panel

The presets grid is built from the JSON files in the theme's themes/ directory, fetched when you open it. If that directory did not come along with the rest of the install, the fetches fail silently and the grid stays empty — copy the whole repository, or git pull in place, and reload.

Settings not saving

Settings are written to the Domoticz server for your user account. Make sure the account you are signed in with has write access, and that the session hasn't expired. If the server can't be reached, changes are kept in localStorage for the current session so the interface still responds — but they won't sync to other browsers, and a hard refresh may lose them.

Filter bar not showing all rooms

Room pills are built from the Domoticz plans API. If a plan has no devices, it won't appear. The filter bar fetches plan data once on init — if it was loaded before plans were ready, reload the page.

Updating

To update Nightglass to the latest version:

bash 
cd /home/pi/domoticz/www/styles/nightglass
git pull

No Domoticz restart required for updates — the browser loads the new files on next page visit. Hard-refresh (Ctrl+Shift+R) if you see stale CSS or JS due to browser caching.

Your custom settings, saved presets and per-device icon overrides live on the Domoticz server, not in the theme folder — git pull never touches them.
